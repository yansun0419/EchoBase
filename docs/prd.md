# EchoBase (灵犀) - AI 持续增长记忆库 MVP 需求文档

## 1. 核心理念
本项目旨在打造一个属于开发者个人的“外脑”系统。它不仅是一个书签或笔记的堆砌处，而是一个由 AI 持续介入、自动清洗、提炼并构建关联的知识引擎。系统通过输入非结构化数据（如网页、视频字幕），自动输出结构化的知识图谱与可执行的工作流模板（Skills）。

## 2. MVP 开发规划 (3 周冲刺)

### Phase 1: 基础设施与数据抓取 (第 1 周)
*   **核心任务**：打通数据入口，建立缓冲机制。
*   **功能点**：
    1.  开发浏览器扩展（Chrome/Edge），实现网页内容截取与 B 站视频字幕提取。
    2.  搭建 Go 语言后端服务，暴露接收数据的 API。
    3.  部署 PostgreSQL 数据库，存储未清洗的原始长文本和元数据。
    4.  引入后端消息队列（或定时任务），平滑 API 请求，为后续 AI 处理建立安全缓冲池。

### Phase 2: AI 引擎介入与向量检索 (第 2 周)
*   **核心任务**：实现“自生长”处理逻辑，构建混合检索底座。
*   **功能点**：
    1.  接入免费大模型 API（如 Google Gemini 或通过 OpenRouter 接入开源模型）。
    2.  编写 Go 后端守护进程，从数据库消费待处理的原始数据，调用大模型生成摘要、提取分类标签。
    3.  集成大模型 Embedding 能力，将文本转化为向量。
    4.  接入 Pinecone 云端向量数据库，实现基于语义的向量检索。

### Phase 3: 容错调优与混合问答 (第 3 周)
*   **核心任务**：打造生产级可用性，完善应用层。
*   **功能点**：
    1.  完善系统的容错与降级机制（API 频率超限重试、网络波动处理）。
    2.  实现混合检索架构（RAG）：通过向量检索找到相关 ID，回源 PostgreSQL 获取原始文本，交由 AI 生成最终答案。
    3.  保证所有 AI 输出必须 100% 附带原始文档的关联溯源链接。
